# PayPal AI Hackathon: requirements (as supplied by the team)

Source: pasted by the team from the Devpost Requirements section. The Official Rules
document was NOT available to us, so anything about eligibility, IP, licensing details,
or legal terms is unverified. Deadline (unverified, from a third-party listing):
Nov 13, 2026, 1:30 AM GMT+5:30. Confirm on Devpost.

## What to build

Build or update an application that integrates the PayPal developer platform (free
sandbox environment) along with an AI tool, model, or platform of our choice.

Optional sponsor tools: AG Grid, APIMatic, Astropods, Bryntum, Channel3, Elastic,
KERNEL, Postman, Render, Zapier. PayPal provides access to select AI sponsor tools,
but using one is not required. Any AI tool works, as long as PayPal integration is
central to the project.

The project should:

1. Meaningfully integrate at least one PayPal technology, API, SDK, product, or
   developer capability.
2. Meaningfully incorporate AI into the experience or functionality.
3. Demonstrate a working prototype or proof of concept.
4. Be sufficiently documented for the judges to understand and evaluate it.
5. Comply with the Official Rules.

Individual or team. New or existing projects are fine, as long as we make meaningful
progress on the project during the hackathon.

## What to submit

- **Project**: built with the required developer tools, meeting the requirements above.
- **Text description**: explains the project's features and functionality.
- **Functional demo**: judges must be able to run or interact with a working build.
  Satisfied by either (a) clear, complete setup and run instructions in the repo so
  judges can build and run it themselves, or (b) a hosted demo URL. A design mockup,
  static prototype, or non-functional demo does NOT count.
- **Tools**: identify which tools (model or AI service) were used and explain how.
- **Public code repository** on GitHub, GitLab or Bitbucket:
  - contains all source code, assets, and instructions needed to run the project
  - public and open source, with a license file visible at the top of the repo
    (in the About section)
- **Demo video**:
  - under 3 minutes (judges aren't required to watch past that)
  - shows the project functioning on the device it was built for
  - uploaded to YouTube, publicly visible, link on the submission form
  - no third-party trademarks or copyrighted music/material without permission
